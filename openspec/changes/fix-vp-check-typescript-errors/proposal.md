- Add missing exports to `index.d.ts`: `launch()`, `version()`, `Browser` interface, and 8 missing `Page` methods (`goto`, `locator`, `close`, `content`, `title`, `url`, `evaluate`, `video`)

- Add `"ES2024"` to tsconfig `lib` to fix `Promise.withResolvers()`
- Fix `packages/trace-viewer/vite.config.ts` type mismatch between `vite-plus` `defineConfig` and `@vitejs/plugin-react`
- All fixes are type-declaration and config-only — no runtime behavior changes
